Alur kerja

Tiga langkah sederhana untuk membuat web ini live

1

Upload file ke GitHub

Buat repository public, lalu upload index.html dan folder images.

2

Aktifkan GitHub Pages

Buka Settings → Pages → pilih branch main dan folder /root.

3

Ganti data sapi

Isi nama sapi, bobot, harga, dan foto asli agar katalog terlihat semakin meyakinkan.

FAQ

Pertanyaan yang biasanya muncul

Bisakah foto diganti dari HP?

Bisa. Kamu cukup upload file foto ke folder images di GitHub, lalu ubah nama file yang dipanggil di HTML.

Apakah web ini cocok untuk GitHub Pages?

Cocok. Ini dibuat sebagai website statis, jadi langsung bisa dipakai tanpa server tambahan.

Kalau data sapi bertambah bagaimana?

Tinggal salin satu objek data di bagian JavaScript, lalu isi nama, bobot, harga, dan foto baru.
